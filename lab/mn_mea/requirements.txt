# ВИДЕОКАРТА НЕОБЯЗАТЕЛЬНА. Без неё всё считается на процессоре, backend.py
# выбирает путь сам.
#
# Если видеокарта есть и нужен счёт на ней — ставьте cupy ВМЕСТЕ с его
# CUDA, одним согласованным набором:
#
#     pip install "cupy-cuda13x[ctk]"    # драйвер держит CUDA 13.x
#     pip install "cupy-cuda12x[ctk]"    # драйвер держит CUDA 12.x
#
# Какой из двух — смотрите в nvidia-smi, поле «CUDA Version» справа вверху:
# это потолок драйвера. Системный CUDA Toolkit не нужен, нужен только
# драйвер: скобка [ctk] притащит компоненты CUDA той же версии, под которую
# собран сам cupy.
#
# Скобку [ctk] пропускать НЕЛЬЗЯ, и вот почему. cupy сам подхватывает
# найденные в окружении пакеты CUDA и подсовывает их заголовки NVRTC. Если
# набор разнородный — скажем, cupy-cuda12x рядом с отдельно поставленным
# cuda-core, — заголовки не сойдутся, и первое же ядро не соберётся:
#
#     error: incomplete type "__nv_fp8_e8m0" is not allowed
#
# Ставить cuda-core, cuda-bindings и прочие nvidia-* руками не нужно.
# Ставить cupy в засорённое общее окружение — тоже: делайте venv.
#
